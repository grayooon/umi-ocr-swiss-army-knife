## 已发布文件与当前源码的区别

v1.1.0 的三个插件 ZIP 发布时，包内版本文件仍写作 `1.1.0-rc.1`。这是历史标记不一致，不能通过重命名 ZIP 修复包内内容。现有 ZIP、下载地址和历史标签保持原样，避免相同下载地址悄悄返回不同文件。

当前主分支已修正文档与版本标记，并包含发布工具维护。因此当前主分支不是既有 v1.1.0 标签的逐字节副本。本地重新打包的文件只用于验证，不应覆盖线上同名附件。

Release 实际提供三个插件 ZIP；`SHA256SUMS.txt` 是可选独立校验清单，不是运行依赖。是否附带清单以 Release 实际附件为准。GitHub 自动生成的 `Source code` 是标签对应源码，不是额外插件。
