# v<版本号> — 三插件发布

本项目为 Umi-OCR 社区插件合集，提供 PP-OCRv6 通用文字、HyperLPR3 车牌和 ddddocr 验证码识别。

## 下载

- `PPOCRv6_ONNX_CPU-v<版本号>.zip`：通用文字插件。
- `HyperLPR3_Plate_CPU-v<版本号>.zip`：车牌插件。
- `DDDDOCR_Captcha_Umi-v<版本号>.zip`：验证码插件，含经典/Beta 接口。

- `SHA256SUMS.txt`：可选校验清单，仅对应本次附件 ZIP；不是插件运行依赖。

这些 ZIP 包含源码和安装器，首次安装需要联网下载依赖与模型，不是带齐二进制的离线完整版。安装完成后可在本机离线识别。GitHub 自动提供的 Source code 是对应标签的整仓源码，不是额外插件；它们不在上述校验清单中。

## 安装

解压所需插件，将插件文件夹复制到 `UmiOCR-data\plugins\`，退出 Umi，运行插件内 `tools\01_setup_online.bat`，然后运行 `tools\02_self_check.bat` 并提供一张合适的图片。重新启动 Umi 并选择插件。完整步骤见仓库 README。
